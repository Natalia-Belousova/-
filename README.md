# Book Tracker

**Автор:** [Твоё Имя и Фамилия]

## Описание
Приложение для любителей чтения, которое помогает вести список прочитанных книг, указывая автора, жанр и объем произведения.

## Функционал
- **Добавление книг:** Удобная форма для записи новых данных.
- **Умная фильтрация:** Поиск по жанру или отбор "толстых" книг (более 200 страниц).
- **Надежное хранение:** Сохранение всей библиотеки в файл `books.json`.
- **Валидация:** Проверка на пустые поля и корректность ввода страниц.

## Как использовать
1. Запустите `main.py`.
2. Введите данные о книге и нажмите "Добавить книгу".
3. Используйте фильтр вверху таблицы, чтобы найти нужные произведения.

## Тесты
- Введите в поле страниц текст вместо числа — программа выдаст ошибку.
- Поставьте галочку "Более 200 страниц" — в списке останутся только объемные книги.
